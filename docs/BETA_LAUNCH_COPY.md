# 베타 100팀 모집 — 광고 문구·소재 세트

대상은 청소업 사장님(40~60대, 스마트폰은 카카오톡 수준)입니다. 아래 문구는 전부 그 기준으로 썼습니다.

지켜야 할 것
- "AI"라는 말은 쓰지 않습니다(우리가 만들어주는 기능은 "전문가 데이터 기반 / 자동"). 단, ChatGPT·Gemini 같은 외부 검색을 가리킬 때의 "AI 검색"은 그대로 씁니다.
- 사전신청·대기 명단 페이지는 만들지 않습니다. 광고 클릭 → 바로 가입 → 바로 사용입니다.
- 할인 조건(승계 불가)을 소재마다 한 줄로 밝힙니다. 나중에 말이 달라지면 그게 분쟁이 됩니다.
- 수익 보장·과장 표현 금지("월 500만원 보장" 같은 문구는 결제망 심사와 광고 심의 모두에서 걸립니다).

공통 링크: https://qualio.co.kr (가입은 상단 "무료로 시작")

## 1. 핵심 메시지 (모든 소재의 뼈대)

한 줄: 청소는 사장님이, 영업은 퀄리오가.
제안: 베타 100팀에 들어오시면 지금은 전 기능 무료, 유료로 바뀐 뒤에도 평생 반값.
근거: 견적·예약·알림톡·홍보 글까지 자동. 들어온 일만 정리하는 장부앱이 아니라 새 손님을 데려오는 도구.
조건: 가입 순서대로 자동 적용. 해지 후 재가입·업체 양도 시 승계 안 됨.

## 7. 자주 받을 질문 (응대 문구)

"평생 반값이면 나중에 얼마인가요"
> 성장 플랜 기준 정가 29만원인데 사장님은 계속 14만 5천원입니다. 플랜을 올리셔도 반값은 그대로 적용됩니다.

"지금은 얼마인가요"
> 베타 기간에는 한 푼도 안 내십니다. 카드도 등록 안 하셔도 됩니다.

"베타면 오류 많은 거 아닌가요"
> 있습니다. 대신 화면 안에 오류 신고 버튼이 있어서 누르시면 저희가 바로 확인합니다. 먼저 들어오신 분들 덕분에 고쳐지는 구조라 평생 반값으로 보답드리는 겁니다.

"쓰다가 그만두면요"
> 언제든 그만두실 수 있고 위약금 없습니다. 다만 해지하고 나중에 다시 가입하시면 그때는 반값 혜택이 없습니다.

## 8. 광고 성과를 볼 때

노출·클릭은 보지 않습니다. 봐야 할 것은 두 개입니다.
- 가입 수 (베타 번호가 자동으로 올라갑니다 — /admin/businesses에서 확인)
- 가입한 곳이 실제로 첫 세팅을 끝냈는지 (/admin/onboarding-gaps에 남아 있으면 아직 못 쓰고 있는 것)

가입만 늘고 세팅이 안 끝나면 광고를 늘릴 때가 아니라 온보딩을 고칠 때입니다.
