5. 발송 근거 (심사 반려 시 이의신청에 쓸 설명)

이 메시지는 수신자가 직접 의뢰해 완료된 청소 작업에서 파생된 후속 안내입니다.

첫째, 수신자의 행동이 선행합니다. 고객이 청소를 의뢰하고 작업이 완료된 건에만 발송됩니다.
작업 이력이 없는 대상에게는 발송되지 않습니다.

둘째, 이 안내는 이미 고지된 내용의 이행입니다. 작업 완료 후 고객에게 발송한 작업 보고서에
"○년 ○월쯤 다시 점검해 보시길 권해드립니다. 그때 저희가 먼저 연락드리겠습니다"라는 문구가
포함되어 있으며, 고객은 그 보고서를 이미 수신했습니다. 본 메시지는 그 예고된 연락입니다.

셋째, 문안에 광고성 요소가 없습니다. 가격, 할인, 이벤트, 예약 유도 문구가 일절 없으며,
버튼도 판촉 페이지가 아니라 고객이 이미 받은 작업 보고서를 다시 여는 링크입니다.
내용은 작업 당시 현장에서 확인된 사실과 그 점검 권장 시점뿐입니다.

넷째, 수신거부 수단을 별도로 운영합니다. 고객이 수신거부한 번호는 발송 대상에서 제외됩니다.

6. 승인된 뒤에 할 일

승인 코드를 받으면 환경변수 한 줄만 넣으면 전환된다. 코드는 이미 준비돼 있다.

  npm run key
  → SOLAPI_TEMPLATE_ID_CARE_CHECK 에 승인된 템플릿 ID 입력

넣기 전에는 문자(LMS)로 나가고, 넣는 순간부터 알림톡으로 나간다.
알림톡 실패 시에는 자동으로 문자로 넘어가므로 중간에 끊기지 않는다.
